# V6 No colour needed

`TestScreenCachedLineAndErrorLineDifferInPlainText` renders the V4 fixture plus a second failing provider with no cache (`gemini`, `offline`) through a renderer with the `termenv.Ascii` profile. The frame carries no escape codes. The cached card has `│ ◌ cached · fetched 14:20:05 · timed out after 10s` and still draws its bar (`━━━━━━━━━━━━━━━━━━─…`); the uncached card has `│ error: offline`. The two states differ by text alone: the glyph `◌` and the word `cached` against `error: `.

Faint styling adds to the state where colour exists (`TestScreenCachedBarsRenderFaint`, `TestCachedProviderCardDimsBarsAndKeepsTheText`, `TestCompactBarDimRendersBarPercentAndCountdownFaint`); with the Ascii profile it is absent and the text still tells the truth.
