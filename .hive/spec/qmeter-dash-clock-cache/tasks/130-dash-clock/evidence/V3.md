# V3 Drop order

Test: `TestHeaderLineDropsNowThenTheWholeRightSide` in `internal/dash/layout/screen_renderer_test.go`. Each case checks the exact line and that it has exactly the requested width in cells.

## Deviation from the source table

The drop order cannot be reached through `layout.Screen`. The screen floor is 80 columns and the header left side is 32 cells plus the digits of the three counts, so the full right side (31 cells) fits at 80 columns unless the counts reach about ten million windows. The test therefore calls `headerLine` directly from `screen_renderer_test.go`, the existing package-internal test file. That file is outside the brief's source table. The manager was told by inbox before the work went on.

Cases (left side `qmeter 1 provider · 0 windows · 0 balances`, 42 cells):

| Width | Right side |
| --- | --- |
| 74 | `fetched 21:23:41 · now 14:22:07` (least width for the full side) |
| 80 | full side, padded |
| 73 | `fetched 21:23:41` alone |
| 59 | `fetched 21:23:41` alone (least width) |
| 58 | left side only, padded with spaces to 58 cells |
| 30 | left side cut with `…` (unchanged behaviour) |
