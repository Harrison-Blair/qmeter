# V2 — Spec paths are not ignored

Command:

```text
git check-ignore -v .hive/spec/qmeter-simplify/README.md .hive/spec/qmeter-simplify/x.json
```

Output after commit:

```text
.gitignore:17:!.hive/spec/**    .hive/spec/qmeter-simplify/x.json
```

The README is tracked, so `git check-ignore -v` omits it. The JSON path matches the negated allow rule. `git check-ignore -q` returned 1 for each path, which confirms that neither path is ignored.
