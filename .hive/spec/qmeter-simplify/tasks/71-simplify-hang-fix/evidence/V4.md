# V4: Root cause

Bubble Tea v1.3.10 groups adjacent printable input into one `KeyMsg` (`key.go:695-702`). In release `internal/dash/model.go:180`, qmeter matched the full `msg.String()` against `q` or `r`, so rapid `rq` input matched neither key and the dashboard ignored it while the fetch continued.

The task branch checks unpasted, unmodified multi-rune messages before the single-key switch. It handles quit first, then refresh. V1 shows that the combined-key test fails on the release base and passes on this branch.
