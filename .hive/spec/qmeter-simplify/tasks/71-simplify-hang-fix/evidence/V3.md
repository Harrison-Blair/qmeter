# V3: Quit during a blocked fetch

I ran:

```sh
go test ./internal/dash -run 'TestRun_QuittingCancelsTheFetchInFlight' -count=1
```

The program-level test uses `Run` with pipe input and output. Its fake provider blocks until the fetch context ends. The `q`, `ctrl+c`, and combined `rq` cases all passed. Each run exited within 1s, and the test confirmed that quit canceled the fetch context.
